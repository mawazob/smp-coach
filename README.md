# SMP (Self-Made Program) Performance Coach

A small Python tool that predicts whether a day's habits will hit a 10,000-step goal, then gives a short coaching message for that day.

## What does it do?

1. Reads a daily log from `smp_log.csv` (sleep, water, bench press, and whether the 10k-steps goal was hit).
2. Trains a scikit-learn `RandomForestClassifier` on that history (80/20 train/test split, `random_state=42`). The trained model is saved with `joblib` and reloaded on later runs instead of retraining.
3. For each new day, predicts **HIT** or **MISS** and reports how confident the model is.
4. Adds a coaching message chosen from a set of templates, based on the prediction and whether sleep and water were above the thresholds (7 hours of sleep, 8 glasses of water).
5. Prints a formatted report for every day, then a summary: hit and miss counts, average confidence, and how sleep and water differed between hit days and miss days.

## Why does it exist?

This is a learning project for Python and machine learning with scikit-learn. It ties together the main steps of a small ML application: loading data, training and saving a classifier, using its predictions on new data, and turning the results into a readable report.

## How do you run it?

**Requirements:** Python 3.9 or newer.

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# 2. (Recommended) create a virtual environment
python -m venv .venv
source .venv/bin/activate        # on Windows: .venv\Scripts\activate

# 3. Install the dependencies
pip install -r requirements.txt

# 4. Add your data file (see below), then run
python smp_coach.py
```

**Data file.** Put a file named `smp_log.csv` in the project folder with these columns:

| Column          | Meaning                                         |
|-----------------|-------------------------------------------------|
| `sleep_hr`      | Hours of sleep                                  |
| `water_glasses` | Glasses of water                                |
| `bench_kg`      | Bench press weight in kg                        |
| `steps_10k`     | `1` if the 10k-steps goal was hit, `0` if missed |

The first run trains the model and saves it as `smp_coach_model.joblib`. Later runs reload it. If you change `smp_log.csv`, delete `smp_coach_model.joblib` once so the model retrains.

**Your own days.** The days to analyze are listed in `incoming_days` inside `smp_coach.py`, as `(label, sleep_hr, water_glasses, bench_kg)`. The sleep and water thresholds (`SLEEP_MIN`, `WATER_MIN`) are at the top of the file.

Confidences and coaching text depend on your data. This is an example:

```

==============================================================

Day 29

  Inputs:   sleep=8.0h  water=10gl  bench=92kg
  Coach:    Strong inputs, strong output. Baseline is locked in. Keep this pattern consistent.

Day 30
  Outcome:  MISS GOAL (94% confidence)
  Inputs:   sleep=5.5h  water=4gl  bench=70kg
  Coach:    Both inputs are below threshold. A reset is required. 8 hours sleep minimum. 10 glasses water tomorrow. No shortcuts.

... one block per day ...

==============================================================
    SUMMARY
==============================================================

  Days analyzed:    7
  Goals hit:        4 / 7  (57%)
  Goals missed:     3 / 7  (43%)
  Avg confidence:   94%

  On HIT days:
    avg sleep:  7.9h  |  avg water: 9.2 glasses

  On MISS days:
    avg sleep:  5.8h  |  avg water: 5.0 glasses

  HIT days averaged +2.0h more sleep and +4.2 more glasses of water

==============================================================
    End of report
==============================================================
```

## Notes

- With a small log (for example 28 days), the 20% test split is only a handful of days, so any accuracy figure will be rough.
- The coaching messages are fixed templates, not generated by an AI model, so no API key is needed.
